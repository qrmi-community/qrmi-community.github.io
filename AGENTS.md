# AGENTS.md

Guidance for AI coding agents working on this repository. Read `README.md`
first: it covers running, layout and common edits.

## What this is

The QRMI community website: a Hugo static site with its own layouts and CSS (no
theme, no Node, no JavaScript). Deployed to
<https://qrmi-community.github.io/documentation/> by `.github/workflows/hugo.yml`.

## Conventions

- Content lives in front matter and `data/*.yaml`; templates only render it.
  Prefer adding data over adding templates, and reuse `layouts/partials/`.
- Every fact on the site (dates, rooms, affiliations, authors, repo
  descriptions) must come from a source: the conference program, the paper on
  arXiv, or the repository README. Do not invent details. Check new URLs load
  (private repos return 404 to visitors and must not be linked).
- The site is served under `/documentation/`. Build internal links with
  `.RelPermalink`, `relURL` or `relref`, and menu entries with `pageRef`.
- `buildFuture = true` so upcoming tutorials are published; `date` decides
  upcoming versus past.
- Presenter photos are square JPEGs in `assets/images/presenters/`, named
  `first-last.jpg`. SC conference photos come from the presenter's page on the
  conference program site.
- Link-preview images are generated by `layouts/partials/social-card.html`.
  After changing titles or that partial, look at the generated card images.
- Every page needs a `description` (at most about 160 characters) in its front
  matter: it feeds the meta description, link previews and tutorial event data.
- Privacy: the site sets no cookies, runs no analytics and loads nothing from
  other domains; the only browser storage is the `theme` key in local storage.
  The footer in `layouts/_default/baseof.html` says so. If a change adds
  cookies, analytics, tracking, embeds, or third-party scripts, fonts or images,
  update that statement in the same change and tell the maintainers.
- Keep CSS in `static/css/style.css`, using the colour variables so light and
  dark modes both work.

## Verify

A developer may be running `hugo server` in this directory. Never write to or
delete `public/`; build into a temporary directory and use a separate port:

```bash
hugo --quiet --destination /tmp/qrmi-site   # must build with no errors or warnings
hugo server --renderToMemory --poll 700ms --port 13131   # then open http://localhost:13131/documentation/
google-chrome --headless=new --screenshot=/tmp/page.png --window-size=1100,1500 \
  http://localhost:13131/documentation/      # optional visual check
```

Stop any server you started when done. A developer's server without `--poll`
misses templates replaced by `sed -i`, so edit layouts in place.
